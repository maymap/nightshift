# 深夜審核台 · Night Shift 👁️

> 凌晨三點，你是這個時段最後一道防線。
> 一則一則，查證、裁定——把有害的移除，把無辜的放行。
> 你以為，你只是在做你的工作。

一款用**純 HTML / CSS / JavaScript**（零依賴、單一檔案）打造的內容審核敘事遊戲。一場班次約 10–15 分鐘。你不會只是憑感覺按按鈕——你得**查證**、**判斷**、**承擔後果**。剩下的，留給你自己在凌晨三點發現。

**▶ 線上遊玩：** https://maymap.github.io/nightshift/

## 玩法

- 讀一則被標記的內容，用工具**查證**再裁定：違反準則 → **移除**；否則 → **核准**。
- **[查作者]／[比對紀錄]／[展開全文]**：表面往往不是真相——查了才知道該怎麼判。
- **兩種錯都要付出代價**：錯放讓傷害擴散，錯刪壓下真相，都算在你頭上。
- 盯著上方的**正確率**、**穩定度**，還有**有限的查證額度**——你沒辦法每一則都查。
- 準則會隨班次越收越緊。有些判斷，沒有正確答案。

## 特色

- **查證迴圈**：比對紀錄、追查作者、展開全文，抓出移花接木、藏起來的人肉、看似威脅的玩笑。
- **後果會回頭**：你放行的內容，會在稍後的複審裡變成記在你名下的傷害。
- **四種結局** ＋ 一個藏在標題列的**結局收集**（自己找找看）。
- **重玩才看得懂**：這不是玩一次就結束的東西。它每一次會多告訴你一點。

## 技術

- **零依賴、零建置**：單一 `index.html`，原生 JS，一個小型狀態機驅動所有場景與分支。
- **把瀏覽器 API 當敘事工具**：`localStorage`（跨場記憶與進度）、即時時鐘、`Page Visibility` 等，讓「介面的行為」本身成為敘事的一部分。
- **音效**：純 `Web Audio` 生成的環境音與音效（無音檔），標題列可靜音。
- **氛圍**：CRT 掃描線 + 磷光終端機配色（IBM Plex Mono / Sans）、打字機效果、glitch 文字。
- **無障礙**：尊重 `prefers-reduced-motion`、鍵盤焦點可見、語意化按鈕。
- **RWD**：桌機與手機皆可玩。

## 本地執行

因為用到 `localStorage`（在 `file://` 下受限），建議開一個本機伺服器：

```bash
python3 -m http.server 8000
# 或
npx serve .
```

然後開 `http://localhost:8000`。

## 部署（GitHub Pages）

純靜態站，`index.html` 在根目錄，直接由 GitHub Pages 服務（`Settings → Pages → Deploy from a branch → main / root`）。`.nojekyll` 已包含。

## 內容提醒

包含監控、失去自主、被凝視般的不安感，以及審核工作會碰到的沉重內容（威脅、傷痛的自述等），皆以克制方式呈現。遊玩中若覺得「介面怎麼怪怪的」，那是設計的一部分，不是 bug。無血腥、無 jump scare。
