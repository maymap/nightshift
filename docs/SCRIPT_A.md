# 深夜審核台 — A 版劇本設計（記憶＝待審內容）

> 設計藍圖，不是最終台詞。台詞用「原始情緒語氣」寫（有畫面感、evocative）。
> 現有 `index.html`（現版）不動；A 版另存、另網址，供並排比較。

## 一句話

你是夜班內容審核員。你審核的「有害內容」，其實是你**對一個你失去的人的記憶**。系統把悲傷判定為不穩定、有害，提供「清除服務」——而你今晚 02:58 簽了字。這個夜班，是你自己的記憶清除，偽裝成一份工作。

**核心動作有了重量：** 移除＝忘掉他一點（系統喜歡、配合度↑、自我↓）；核准＝留住這段記憶（被標記為異常、配合度↓、自我保住）。

**貫穿問題：** 到早上，還剩下幾個你？

---

## 系統：兩條儀表

| 儀表 | 起始 | 移除時 | 核准時 | 意義 |
|---|---|---|---|---|
| **配合度** | 100 | ↑ | ↓ | 系統對你的評價 |
| **自我** | 100 | ↓（刪掉一塊自己） | 0（保住） | 你還剩多少 |

兩條同時顯示。玩家會直接看到「討好系統」與「保住自己」在對撞。這是把主題變成**看得見的系統**。

---

## 三幕結構

### Act 1 — 值班（正常，鬆懈期）
- 建立規則與兩條儀表。
- 幾則「看似陌生人」的日常訊息，但夾帶只有你會懂的細節（種子）。
- 收尾：第一個「等等，這好像跟我有關」。

### Act 2 — 滲漏（這是我的記憶）
- 訊息明顯是你的：出現他的名字、你們的地方、你的字跡。
- 系統把它們標成「有害／不穩定」，施壓你刪。
- 介面開始出手：覆寫你的裁定、趁你不看改動、假游標。
- 中段揭露：上一位操作員 #4477 的紀錄＝過去的你（已被清除的你）。

### Act 3 — 校準（刪到剩你）
- 系統宣布要清除「剩餘不穩定資料」＝剩下的你。
- 最終案件＝關於他的最後一則記憶，或你的意識本身。
- 依 **自我 × 最終抉擇** 分歧到結局。

## 記憶碎片清單（setup → payoff）

每則帶：碎片 ID、表面來源、真實身分、儀表效果、揭露旗標。
「他」＝你失去的人（先用代稱，命名見下方待決）。

| # | 表面 | 真實（回收） | 幕 |
|---|---|---|---|
| F1 | 陌生人抱怨地鐵誤點 | 你每天搭那班車去見他 | 1 |
| F2 | 老陳分享泡麵宵夜食譜 | 那是你和他最後一起吃的宵夜 | 1 |
| F3 | 有人問「刪掉的東西為什麼會回來」 | 你刪過關於他的貼文，但它一直回來——因為你放不下 | 1→2 |
| F4 | 「為什麼我看到的跟別人不一樣」（文字變形） | 你的記憶正在被竄改：他的臉開始模糊 | 2 |
| F5 | 一張你們的合照描述 | 照片裡他的位置，已經是空白 | 2 |
| F6 | 系統覆寫你的裁定 | 你想留的，系統替你刪了 | 2 |
| F7 | 「#4477，是你嗎？我在另一邊」 | 上一個承受不住、被清除的你 | 2 |
| F8 | 「請把視線移開螢幕」 | 趁你不看，他又少了一點 | 2 |
| F9 | 02:58 你自己寫的紀錄：「如果我發現我也在被清除…」 | 你簽字同意清除的那一刻 | 2→3 |
| F10 | 最終：關於他的最後一則 | 刪，或留 | 3 |

> 碎片要拼出一個可讀的故事：你失去了他 → 悲傷讓你「不穩定」→ 系統提供遺忘 → 你簽了字 → 這個夜班就是你在親手忘記他。

## 結局矩陣（自我 × 最終抉擇）

| 結局 | 條件 | 內容 |
|---|---|---|
| **空白** | 自我 ≈ 0（幾乎全刪） | 你把自己刪光了。系統得到一名乾淨、穩定、再也不會悲傷的操作員。你不記得曾經有過他。 |
| **殘影** | 自我 中間 | 你留下了一點，但不夠。明天你會再回來，再刪一次。你隱約覺得少了什麼。 |
| **異常** | 最後對「他」按下核准／拒絕清除 | 你留住了他。系統標記你為異常，安排重新校準——但今晚，你記得。你反抗過。 |
| **記得** | 自我 極高（幾乎全保留） | 天亮，你記起全部——包括你曾簽字要忘記他。知道，即是懲罰。 |

**結局會回放你的選擇**（payoff）：點名你刪掉／留下了哪些碎片。
例：「你還記得泡麵的味道嗎？」→ 若你刪了 F2：「你把它移除了。」／若留著：「還記得。只剩這個了。」

## 系統化的資料結構（實作方向）

- `story = { acts: [ { id, title, beats: [...] } ] }`，取代目前扁平的 `steps[]`。
- 每個 case beat：`{ id, surface, truth, fragmentId, comply:{ok,rm}, self:{ok,rm}, reveal, mutate? }`。
- 狀態：`kept = []`、`deleted = []`（記錄玩家對每個碎片的處置）。
- 結局：由 `self`、`最終抉擇`、以及 `kept/deleted` **生成**（非固定文字），做到回放。
- 保留現有機制：真實時鐘、tab-away 竄改、localStorage 記憶（回訪時「你昨晚也刪過一次」）、音效、分支。

## 待你拍板的關鍵決定

1. **情感核心**：「失去的人」是最強的一版（也可換成：你抹除的是**你做過的一件錯事**／**一個你不想再當的自己**）。
2. **「他」是誰**：戀人？家人？朋友？孩子？（決定碎片的具體內容與溫度）
3. **兩條儀表 vs 一條**：兩條（配合度＋自我）最能呈現對撞，但畫面較滿；也可只留「自我」一條。
4. **結局要 3 種還是 4 種**（加「記得」那個高難度結局）。
